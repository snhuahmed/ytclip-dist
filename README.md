# YT Clipper — release channel

Download and install files for [YT Clipper](https://github.com/snhuahmed/ytclip).
Source lives in a separate repository; this one exists only to serve release
assets, which Chrome fetches without credentials when checking for extension
updates.

## Install (Windows)

1. Download `ytclip-*-win.zip` from [Releases](../../releases/latest)
2. Unzip it anywhere
3. Double-click `install.bat` — no administrator rights needed
4. Restart Chrome

A Clipper panel appears beside any YouTube video. Updates arrive on their own.

To remove it, run `uninstall.bat` from the same folder. Downloaded videos are
left alone.
